# 온쿡 (OnCook) · 발달장애인 AI 요리 보조 챗봇

> 서울청년기획봉사단 2기 온쉐어 팀에서 출발한 프로젝트로, 발달장애인이 스스로 요리할 수 있도록 돕는 AI 기반 요리 가이드입니다.

---

## 프로젝트 배경

서부장애인종합복지관 자립주거팀 발달장애인 5명을 대상으로 쿠킹클래스를 운영하며, 현장에서 실제 사용할 수 있는 AI 요리 보조 도구를 단독 기획·개발했습니다.

- 서울청년기획봉사단 2기 · 온쉐어 팀장 (2025.03 ~ 08)
- LG Hello Vision 기업 연계 지원금 수령
- **헬로TV 뉴스 취재 · 방송 보도**
- 참여자 만족도 **4.83 / 5점** · SNS 조회수 **16,000+**

이후 연세대학교 사회복지대학원 HEART Lab 초청으로 기술 납품, 모바일 앱([하루메이트](https://github.com/RyanAhn533/Hibuudy))으로 확장되었습니다.

---

## 주요 기능

- **이미지 기반 재료/도구 선택** — 텍스트 입력 없이 사진을 눌러 선택 (43종 재료, 12종 도구)
- **AI 메뉴 추천** — 선택한 재료·도구 기반으로 GPT가 만들 수 있는 요리 추천
- **단계별 레시피 안내** — 한 단계씩 크게 표시, 이전/다음/다시 듣기 내비게이션
- **음성 안내 (TTS)** — 모든 단계를 음성으로 읽어주는 브라우저 기반 TTS
- **손 씻기 체크** — 요리 시작 전 손 위생 상태 확인 단계

---

## 사용자 흐름

```
① 손 상태 확인 + 조리도구 선택 (Home)
      ↓
② 재료 선택 — 43종 이미지 중 보유 재료 터치 선택
      ↓
③ AI 메뉴 추천 — GPT가 재료 기반 추천 → 메뉴 1개 선택
      ↓
④ 단계별 요리 가이드 — 현재 단계 강조 + TTS 음성 안내
```

## 접근성 설계

| 영역 | 적용 원칙 |
|------|----------|
| UI | 이미지 기반 선택, 텍스트 입력 없음, 버튼 크게 |
| 언어 | 쉬운 한국어, 단계당 동작 1개, 숫자는 한글로 |
| 레시피 | 칼 최소화 (가위/손 대체), 약불/중불만 사용 |

| 내비게이션 | 시작/다음/이전/다시/그만 — 5개 버튼으로 조작 |

## 프로젝트 구조

```
Onshare_chatbot/
├── Home.py                   # 메인 — 손 씻기 + 도구 선택
├── recipe_templates.py       # 13종 레시피 DB
├── requirements.txt          # Python 의존성
├── pages/
│   ├── 1_재료선택.py          # 재료 이미지 선택
│   ├── 2_메뉴선택.py          # AI 추천 + 메뉴 선택
│   └── 3_만드는방법.py        # 단계별 레시피 가이드
├── utils/
│   ├── gpt_helper.py         # OpenAI API 래퍼
│   └── ui.py                 # TTS, 이미지 선택, AAC 컨트롤 패널
└── data/
    ├── hand/                 # 손 위생 이미지
    ├── ingredients/          # 재료 이미지 (43종)
    ├── menu/                 # 메뉴 이미지 (12종)
    ├── tools/                # 도구 이미지 (12종)
    └── aac_controls/         # AAC 컨트롤 이미지
```

## 실행 방법

```bash
# 1. 의존성 설치
pip install -r requirements.txt

# 2. 환경변수 설정
#    .env 파일에 OPENAI_API_KEY 설정
echo "OPENAI_API_KEY=sk-..." > .env

# 3. 실행
streamlit run Home.py
```
